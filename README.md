# 🌙 LIFESAVER AI — Last-Minute Life Saver

LIFESAVER AI is an automated productivity engine and mental triage system designed to combat task paralysis. It allows users running on tight crunch deadlines to dump unstructured, anxious brain dumps, syllabus timelines, or scattered notes into a clean dashboard. The application leverages Gemini 2.5 Flash to structurally parse the raw chaos into localized tactical triage grids, color-shifting DEFCON priority feeds, and automated calendar matrices.

## 🧠 Core Application Ecosystem Features

* **🧠 Mental Decompression Chamber (Triage):** Accepts unstructured raw text streams and converts them into structured JSON task blocks complete with atomic micro-steps.
* **⚠️ DEFCON Urgency Command Center:** Automatically tracks task age parameters and escalates uncompleted items from stable watch status directly up to active emergency warnings.
* **📅 Tactical Calendar Matrix:** Maps scheduled execution windows across full monthly grids with individual runtime completion tracking.
